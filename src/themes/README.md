# Themes

How the watch looks: each theme draws every screen in its own way, with
one or more colour schemes, which Settings' THEME row picks between. A
build has the themes its features name (see
[AUTHORING-THEMES.md](../../AUTHORING-THEMES.md), which is also how to
make one); a release's `ur` has Retro, and every other theme has a
package of its own.

| Theme | Feature | Schemes |
|---|---|---|
| [Retro](retro/) | `theme-retro` (the default) | ARCADE and TERMINAL by night, HANDHELD and PARCHMENT by day |
