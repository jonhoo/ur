# The simulator against a dev kit: every screen and input a dev kit can be
# made to show without a phone, frame by frame. With a `compare` build
# flashed (see README.md):
#
#     cargo run --release -- --devkit ../target/thumbv7em-none-eabihf/release/ur \
#         --out ../tmp/compare devkit-compare.txt
#
# What it changes on the dev kit (the theme, an alarm, the battery
# reading) it changes back. (No `steps`: they'd go into the dev kit's
# activity, which a paired phone syncs to Gadgetbridge.) With
# a phone connected to the dev kit, it can't run: the phone's own messages
# can't be followed.
